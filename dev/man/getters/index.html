EcoBase.coordinates — Function
coordinates(plc)
coordinates(asm)

Return the coordinates of the places, as their location data reports them; an assemblage answers for its places.

source
coordinates(loc)

Return two columns of coordinates, one row per place, in whichever order coordinateorder() declares — and, for a grid, at the anchor cellanchor() does.

source
coordinates(loc, order)

Return the coordinates of loc with its two columns in the requested AbstractCoordinateOrder, whatever order it reports them in natively. Places and assemblages answer for the location data they hold.

source
coordinates(grd, order, anchor)

Return the coordinates of grd with its columns in the requested AbstractCoordinateOrder referring to the requested AbstractCellAnchor. Places holding a grid, and assemblages of them, answer for it.
